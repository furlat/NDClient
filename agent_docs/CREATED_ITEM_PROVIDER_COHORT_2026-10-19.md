# Created-item provider cohort — 19 October 2026

Continues Phase4 of the schema/Factory plan. This is a bounded shared item
provider, not complete weapon/history/event integration or user art acceptance.

## What now owns the appearance

Typed `Gear.native_appearance: EffectUse` compiles into the existing native body
index. Flame Blade and Devotee’s Mace select their delivered closed-package
`items/created/.../appearance` clips. Ordinary 2D equipment lookup admits their
native assignment without borrowing another sword sheet. The shared compiler
collects **actual creation ancestry, exact item/creator UUIDs, private inventory
admission and, for Flame Blade, the actual applied lifetime condition UUID**.
The Timeline keeps that passive origin table separately from canonical state.
A small immutable membership/lifetime signature preserves creation→equip→remove
rows even when all share one timestamp. Cached item metadata is not existence.

Preparation uses the same compiled native requirements, EffectPackage/Factory
constructor, renderer passes, receiver depth and owner clock as other effects.
Queued requirements retain hidden instances before the item owner publishes;
inactive items retire their native instance without discarding small provenance.
Main-hand placement samples the current authored optical socket and actual body
sprite basis. Missing offhand sockets remain a named gap. The delivered setter
receives the exact current item/holder/slot/hand/world/lifetime packet. Unseen
cached former holders cannot win over current visible membership; simultaneous
observed holders remain an explicit ambiguity. No public creation origin is
borrowed across faction streams.

The two delivered appearances have absolute material clocks and no particle
history. Their typed EffectUse explicitly selects absolute sampling; the generic
source-simulation default is unchanged. Production and Studio still use one
fold/compiler/Timeline. Studio now indexes actual item eligibility intervals,
source/provenance gaps and original event-trace rendering requirements. Source-only
thumbnails for these context-dependent items are deliberately unqualified: the
real scene preview has their actual hand/body, while a fabricated study grip would
be misleading. No blank private startup draw is labelled as a warm witness.

Flame Blade’s old finite cast vignette no longer creates a weapon/light/attack-hit
on a timer. Its actual cast preparation remains. Owned appearance is under the
real item/lifetime; delivered attack-hit and transfer/lifetime source treatments
still need their real event bindings. They are not silently treated as complete.
Approved 2D lighting/normals/cap/tint/shadows/walls and body/audio timing unchanged.
