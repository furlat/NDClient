## One actual admission path

inventory or placed-object admission, and exact public Factory component.
`CreationInputs` joins native descendants to their immutable event-time commit
after-values. Inventory requires the real false→true holdings row and the same
cut's actual ItemRecord. Placement requires the actual `object_placed` UUID and
matching canonical placement. No current-world diff, nearest object, fabricated
birth UUID, inferred reward or fake ActionFact is used.

item/container UUID stays in the event operand and is never a character geometry

program draws only its supplied admission seam/brackets, never replacement
