  - Fix it by preparing earlier, not by holding the clock. The user's rule is no presentation holds.

## Rules the user set (also in memory)
- **Git:** stage by explicit path, never `git commit -a`, because the VFX Factory writes into `assets/vfx/` at any time. Plain commit messages with NO Co-Authored-By or any other attribution line.
- **Godot hygiene:**
  - absolute `--path C:\Users\tommaso\Documents\Dev\<tree>`;
  - `timeout` on every run;
  - kill only your own leftovers, matched by path, including the windowed child;
  - never kill Godot by name, nor anything under `VFXFactory`;
  - `--headless` when possible.
- **Zero errors:** no failing checks, no script errors, no engine errors, no "Missing" or "not found" lines. Run the live tier after every merge; the user must never be the one to find a crash.
- **Assets:**
  - The client keeps its own copy of every asset, with no links to outside folders. The game ships as one executable without the Factory.
  - Art in `assets/art` is source only; the build packs what ships.
  - Icons and portraits are bound by the client from its own banks, never from the server's keys.
- **No presentation holds:** never freeze the clock to wait for preparation.
- **One path:** no fallbacks to old data. A missing build output is an error.
- **Don't overfit:** the sources cover every delivery and every server id, not just what one map uses.
- **Engines:** never use or modify `/mnt/c/Users/tommaso/Documents/Dev/dnd_engine`; use the exported copies under `/home/tommaso/.cache/ndclient/`. Codex worktrees may only be read.
- **Code style:** match the surrounding GDScript (dense one-liners). No Manager, Registry or Handle classes. In tools and tests use `preload` consts.
