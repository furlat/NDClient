# Production option identities: focused qualification inputs

20 October 2026. Root's shared selector now supports exact public
`SpellFact.effect_id`; this cohort adds durable inputs and a headless test only.
No runtime, typed spell, manifest, source package, shader or art was changed here.

`tests/production_option_identity_checks.gd` reads the actual compiled production
Resource through `NativePresentationSources.find`. It verifies all seventeen
typed literal predicates and empty recipient recipe overrides, then checks
production selection, ordinary Studio event trace, one caster/body owner,
sparse-application declaration inheritance, immutable source/caster recipe and
canonical end-state parity against the independent SDK journal fold.

The predicates are four Bestow Curse options, two Blindness/Deafness options,
six Enhance Ability choices and five Protection from Energy choices. All use
exact `when.effect_id` values already disclosed by native spells. The seventeen
old full TypeScript recipe snapshots are no longer copied into these options;
the current Godot recipe and single caster are inherited. Existing unrelated
Factory alternatives remain unselected drafts.

This is routing/ownership completion, **not seventeen new graphics**. Existing
condition owner/state selection already routes four Bestow Curse conditions,
six Enhance Ability states and five Protection from Energy energy states
(fifteen forms). Their original body/marker lifecycles remain unchanged.
Blinded and Deafened markers are separate existing condition sources.
