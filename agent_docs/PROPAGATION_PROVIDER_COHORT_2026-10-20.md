The package still declares `density_field`. Its selected standalone network
omits `density_mask`; the source's shader inserts density equations only when
that setting is true. This is an explicit **client choice**, not a claim that the
Factory declares the channel optional:

```gdscript
extra.input_policies = {
    "density_field": {
        "mode": "not_applicable",
        "reason": "selected_factory_density_mask_disabled"
    }
}
```

constructor, source default, ribbon capacity, endpoint count, launch and speed.

`unavailable`. No density setter is called and no empty particle field is
invented. The offline coverage join preserves the Factory's declared inputs and
reports the client choice separately. This does not enable liquid density.
