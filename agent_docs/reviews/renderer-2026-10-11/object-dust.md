## Native input and original behavior

The consumer follows `game_obsolete/object_dust.py::object_dust_commands` and `game_obsolete/body_effects.py::silhouette_dust`: source alpha threshold, seeded uint32 noise, horizontal erosion rank, scan order, particle selection, drift/gravity, fade and padding. A complete nonconstruction prop may carry `affected_volume`; only a resulting partial placement excludes it from this whole-prop operator. Construction and actor dust are separate remaining consumers.

The GPU prepares one padded native-source target with a body draw and instanced source-pixel particles. Particle writes preserve original scan-order overwrite semantics. The result uses the same Sprite, receiving-light and viewport path as ordinary images. Source/filter coordinates account for padding. Pan/zoom never enters the dust signature. Native duration is 1150 ms erosion + 1350 ms particle lifetime.

The browser test also exposed and fixed finite-effect membership during canonical object refresh: the world patch was removing the same-owner retained effect at an unrelated animation boundary. World refresh now excludes finite `effect:` contributions; the operation compiler owns their lifetime. Whole-prop disintegration also removes its ordinary frame contribution, if present.
