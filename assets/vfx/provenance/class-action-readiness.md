# Prepared class-action source assets

These are immutable native resources compiled from the selected Factory source equations for Quickened, Twinned and Distant. They are not sampled occurrences. The compiler is `factory/packaging/prepare_class_actions.gd`; runtime source is `factory/components/gpu_motion/class_strips.gd` and its original `fields/class_action.gd` base. Geometry, CIE D65 palette finishing, source material values and noise settings are unchanged. Materials are local to each scene instance; mesh, shader and texture data are shared.

The glow texture retains **Boringdev / Ultimate Magic VFX Pack**, `vfx_1/arc_charge/textures/aura_glow.png`, original SHA256 `0153d00f65f7d86263514a57b5892176816d8fb374ca94325de74e7e667aa820`. Its authoritative inventory and scoped license evidence remain in `catalog/packages/pack_boringdev_ultimate_magic_vfx_pack.json` and the package's existing delivered provenance. Preparing an ImageTexture does not change that artwork's author or license. No new license is inferred.

The flow texture is the original Godot FastNoiseLite/NoiseTexture2D result, frozen after native generation completes: 256×256, seamless, 0.2 blend skirt, mipmaps, noise type3, frequency0.018, fractal type2, four octaves, gain0.55. It is not a substitute noise implementation. The palette texture and strip/core/mote geometry are Factory-authored/generated as in the source.

`program-db1921a6f2ee5bb3.gdshader` is the actual native shader generated by Windows Godot4.7.2 for the original mote StandardMaterial3D. It was obtained through the engine's Material inspection API, with its real native uniforms. It retains the engine's generated header. Godot engine source and license: [material.cpp](https://github.com/godotengine/godot/blob/4.7.2-stable/scene/resources/material.cpp), [MIT license](https://github.com/godotengine/godot/blob/4.7.2-stable/LICENSE.txt). The runtime does not call editor shader inspection. Other programs preserve the original Factory source shaders and numerical palette contract.

No actor, owner, recipient, event outcome, cue identity, owned clock object, advanced age, world placement or fixture observation belongs in these resources. Clock uniforms have neutral zero defaults and the source-space matrix is identity; construction always replaces the slot with the actual occurrence's private slot before publication. The zero-age local transforms are source geometry only; actual sampling, layer masks and clocks remain private. `preparation.json` records the exact selected source phases. Affinity uses a separate open-arc constructor and is explicitly outside this prepared bank.
